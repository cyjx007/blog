怎么拿到这个令牌
  1. 打开 GitHub → 新建 fine-grained token
  2. Token name 随便写，Expiration 选 90 天或更久
  3. Repository access 选 Only select repositories → 选 blog
  4. Permissions → Repository permissions → Contents: Read and write
  5. 生成，复制，粘到上面
